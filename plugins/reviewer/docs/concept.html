the failure that matters

A confident reviewer citing a missing file is worse than a vague one.

Before any brief is written, every path, symbol and convention it mentions is checked to exist.

Blocking

A dead path stops generation. It is fixed, not waved through.

Honest gaps

If the survey found nothing specific, the brief says so and stays general.

Also checked

Graph acyclic, every reviewer reaches the judge, every brief has a Hands off section, nothing secret.

inside :init

Classify, survey, propose, decide, write, verify.

  1. Classify — new build or established codebase; decides whose rules apply.
  2. Survey — six read-only probes; every line carries evidence.
  3. Score — catalog marked take / maybe / skip; discovered reviewers proposed.
  4. Decide — you answer up to four rounds of questions. Nothing is written before this.
  5. Write — briefs in parallel, coordinator last, then pipeline.yml.
  6. Gate — any failure goes back to Write.
  7. Hand over — tree, graph and a README recording what you declined.
the survey

Six questions, then stop reading.

A · charter

What does the project say about itself? CLAUDE.md, CONSTITUTION.md, rules, ADRs, manifests.

B · conventions

Which rules does the code visibly follow? Each needs a demonstrating file.

C · blast radius

Where does a wrong value reach a customer, a regulator or another system?

D · seams

Verbatim payloads, API surface, migrations, queues, shared contracts.

E · hostile input

Uploads, webhooks, LLM and OCR output — traced to where they are used.

F · history

Files that change most and get repaired most, straight from git. Cheap and predictive.

you decide

The plugin proposes; you choose.

  1. Whose rules — established codebases only: project conventions, plus shared gaps as info, or shared standards.
  2. The set — accept, accept and review the "maybe" list, remove some, or see all 28.
  3. Extras — multi-select per group, each with None; irrelevant groups skipped.
  4. Budget — reviewer count, model tiers, trigger bounds; costs spelled out in the options.

Questions are always in English because they shape committed files. Declined reviewers are recorded and not pushed again without new evidence.
